ІНСТРУКЦІЯ ДЛЯ ПУБЛІКАЦІЇ ВЕБСТОРІНКИ

Головний файл архіву: index.htm

1. Розпакуйте архів.
2. Для GitHub Pages завантажте index.htm до кореневої папки репозиторію.
3. У GitHub відкрийте Settings → Pages.
4. Виберіть Deploy from a branch, гілку main і папку /(root), натисніть Save.
5. Після публікації відкрийте адресу сайту, яку покаже GitHub.

Примітка: GitHub Pages зазвичай автоматично розпізнає index.html як головну сторінку. Якщо використовуєте саме index.htm, переконайтеся, що посилання відкриває цей файл; за потреби перейменуйте його на index.html.

Усі інтерактиви працюють у браузері. Журнал спроб доступний у межах сеансу браузера учня; індивідуальний звіт можна зберегти у PDF.
