ІНТЕРАКТИВНИЙ ТРЕНАЖЕР З ІНФОРМАТИКИ
Тема: Програмні засоби для складних обчислень, аналізу даних та фінансових розрахунків

РОЗМІЩЕННЯ НА GITHUB PAGES
1. Створіть новий публічний репозиторій на GitHub.
2. Розпакуйте цей ZIP-архів.
3. Завантажте до кореневої папки репозиторію файл тренажера.
4. Перейменуйте interaktyvnyi_trenazher_informatyka.html на index.html.
5. Натисніть Commit changes.
6. Відкрийте Settings → Pages.
7. У розділі Build and deployment виберіть Deploy from a branch.
8. Виберіть гілку main та папку /(root), натисніть Save.
9. Після публікації GitHub покаже адресу сайту у форматі:
   https://ВАШ_ЛОГІН.github.io/НАЗВА_РЕПОЗИТОРІЮ/

ВАЖЛИВО
- Тренажер працює у браузері, без окремого сервера.
- Дані спроб зберігаються в поточній сесії браузера; вони не передаються автоматично вчителю чи на GitHub.
- Щоб зберегти індивідуальний звіт, учень натискає кнопку PDF та обирає «Зберегти як PDF».
- Файл інструкції PDF можна залишити в репозиторії як допоміжний матеріал.
